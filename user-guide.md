# User Guide

1. Start the backend and frontend using the README instructions.
2. Open `http://localhost:5173`.
3. Choose **Create an account**, enter a valid email and password of at least 8 characters, then submit.
4. Add an application with company, role, location, status, date, optional posting URL and notes.
5. Search by company/role/location and filter by status.
6. Use the edit and delete controls to maintain your pipeline.
7. Use **Export** to download your records as CSV.
8. Use **Sign out** when finished. Each account can access only its own applications.

If the page says the API is unavailable, confirm the backend terminal is still running and visit `http://localhost:8000/health`. The interactive API reference is at `http://localhost:8000/docs`.
